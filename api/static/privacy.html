Privacy policy

Last updated November 8, 2026.

About this demo

VoiceSignal is a research and educational demonstration that classifies precomputed speech-feature values. It is not a medical device and does not diagnose or treat Parkinson's disease. Do not use it to make health decisions.

Feature data you submit

When you request a prediction, the feature values in your selected CSV row or manual entry are sent to this site's prediction API to produce a result and a SHAP explanation of the model output. The demo does not need your name, contact details, voice recording, or other direct identifiers. Do not submit personal, identifying, or sensitive clinical information. The API may be hosted by a cloud provider that processes technical request data to operate and protect the service.

Analytics

When configured for this deployment, this site uses Plausible Analytics to understand aggregate page visits and improve the demo. The integration does not use advertising cookies or collect the feature values submitted for predictions. Plausible processes technical request information, such as IP address and browser details, to provide its service and reports aggregate statistics. Read the Plausible data policy for details. Analytics is not loaded when the deployment has not configured a Plausible site domain.

Cookies and third parties

This site does not set advertising or analytics cookies. The demo uses a hosted prediction service; the API host and its infrastructure provider may process technical information needed to deliver and secure requests. External links, including the API documentation and analytics policy, are governed by their own providers' privacy practices.

Questions

This educational demo does not provide a contact form or collect contact details. If you have questions about its operation, use the project's public repository or deployment support channel.
